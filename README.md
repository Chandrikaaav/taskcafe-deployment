# Taskcafe Deployment

This project demonstrates the deployment and configuration of the open-source **Taskcafe** project management tool using **Docker** and **PostgreSQL**.

## 📋 Overview
Taskcafe is a self-hosted project management application similar to Trello.  
In this project, Taskcafe was containerized and deployed using Docker for simplified setup and scalability.

## ⚙️ Tools & Technologies
- Docker
- Docker Compose
- PostgreSQL
- Taskcafe (Open Source)

## 🚀 Deployment Steps
1. Cloned the Taskcafe repository.
2. Configured PostgreSQL database credentials.
3. Built and started containers using Docker Compose.
4. Accessed Taskcafe through the local web interface.

## 🧠 Learning Outcome
- Understood containerized deployments using Docker.
- Gained hands-on experience configuring PostgreSQL for web applications.
- Learned how to manage multi-container applications efficiently.
