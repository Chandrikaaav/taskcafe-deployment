# 🧠 Taskcafe Deployment (Docker Setup)

This project demonstrates the **deployment of Taskcafe**, a task management web app (similar to Trello), using **Docker** and **PostgreSQL**.

---

## 🚀 Project Overview
Taskcafe is an open-source project management tool built using **Go**, **React**, and **PostgreSQL**.  
In this project, I deployed Taskcafe using **Docker Compose** to simplify setup and configuration.

---

## ⚙️ Technologies Used
- Docker
- Docker Compose
- PostgreSQL
- Taskcafe (Go + React)
- Command Line / Terminal
